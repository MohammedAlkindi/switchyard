How Switchyard coordinates agent execution.

A deterministic pipeline keeping agent operations sandboxed, observable, and ready for human review.

Step 01

Spawn Worktrees

fleet spawn <name> generates a linked Git worktree under .fleet/agents/ and checks out a private branch.

.fleet/agents/api
Step 02

Route & Audit

Worktree agent invokes localhost:52425/v1. Fleet Gateway proxies completions directly to your provider and records costs.

.fleet/audit.jsonl
Step 03

Collision Check

fleet check calculates index-tree diff intersections across all active worktrees to detect concurrent file overlaps.

fleet check --json
Step 04

Gate & Merge

fleet validate executes your repo test suites. fleet merge lands verified, collision-free code into main.

fleet merge api
