Privacy Policy

Effective Date: November 7, 2026 · Version: 1.0.0 · Zero-Telemetry Guarantee

1. Principle of Local Sovereignty

Switchyard is designed from the ground up as a strictly local-first developer tool. Our software runs entirely on your local workstation. Switchyard does not operate an account system, user database, remote tracking server, or cloud telemetry pipeline.

2. Zero Telemetry & Zero Analytics

Switchyard and its associated packages (@switchyardhq/switchyard, @switchyardhq/contextbill, @switchyardhq/cortexai) contain zero analytics, tracking beacons, heartbeat pings, or diagnostic phone-homes. When you execute commands in your terminal or use the browser-based review viewer:

  • No usage events, execution counts, or timestamps are sent to us or any third party.
  • No IP addresses, MAC addresses, machine identifiers, or hardware specifications are collected.
  • No crash reports or error stack traces are automatically transmitted outside your device.

3. Source Code, Git Worktrees & Transcripts

Your intellectual property belongs exclusively to you. When Switchyard isolates coding agents, creates Git worktrees, calculates index-tree diff collisions, or analyzes context billings:

  • Source Code & Diffs: All Git operations occur strictly through local git subprocess invocations within your repository. Your source code never leaves your workstation.
  • Agent Transcripts: Contextbill and Switchyard inspect session JSON logs strictly on your local disk. Transcripts are never uploaded, summarized in the cloud, or retained on remote servers.
  • Review Viewer: The browser-based review tool (review.html) processes JSON reports using purely client-side JavaScript via the browser File API. No file data is uploaded over the network.

4. Fleet Gateway & LLM API Communications

When utilizing the local Fleet Gateway (fleet gateway / packages/cortexai), the gateway acts strictly as a local reverse proxy running at 127.0.0.1:52425:

  • Direct-to-Provider Routing: API requests generated by your agents are relayed directly from your machine to the upstream AI provider endpoint configured in your local environment (such as Anthropic, OpenAI, or a self-hosted Ollama server).
  • Zero Intermediary Servers: Traffic does not pass through any proxy server operated by Switchyard. We never see, store, or intercept your prompts, completions, or API keys.
  • Local Audit Trails: The gateway records request metadata and calculated costs exclusively to your local .fleet/audit.jsonl file for your personal auditing and transparency.

5. Credential & Secret Protection

Switchyard enforces strict secret hygiene:

  • API keys and provider credentials provided via .env or .env.fleet remain solely on your local filesystem and are automatically added to .gitignore upon initialization.
  • Switchyard never prints unmasked authentication tokens, authorization headers, or private keys to log outputs or CLI displays.

6. Website Hosting & Cookies

The Switchyard documentation website (switchyardhq.vercel.app) is a static website deployed on Vercel.

  • We do not set tracking cookies, marketing cookies, or persistent profiling identifiers.
  • The website enforces a strict Content Security Policy (CSP), HTTP Strict Transport Security (HSTS), and standard protective HTTP security headers.
  • Any web server logs retained by the hosting infrastructure (such as standard CDN access logs) are handled in accordance with Vercel's privacy policies and are used solely for delivery and DDoS mitigation.

7. Independent Verification

Switchyard is open-source software licensed under the MIT License. The complete source code, build scripts, and dependencies are publicly auditable in our GitHub repository:

https://github.com/MohammedAlkindi/switchyard ↗

8. Contact & Security Reports

If you have questions regarding this policy or wish to report a security concern, please open an issue on the official GitHub repository or contact Mohammed Alkindi directly via the project repository.
