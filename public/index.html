Install & isolate 
npm install -g @switchyardhq/switchyard
# Inside an existing Git repository:
fleet init
fleet spawn api
fleet spawn auth
fleet dashboard --once

Switchyard creates worktrees. It does not start an AI worker for you.

Understand the signal

A clean snapshot is a starting point.

Uncommitted work cannot be simulated. Validation can become stale when a branch or command changes. A file-only overlap is not a predicted conflict. The review keeps these distinctions visible; it never treats a report as permission to merge.
