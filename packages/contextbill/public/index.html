Four steps, all of them local.

  1. 01Run npx contextbill — no install, no config, no API key.
  2. 02It reads transcripts from disk — ~/.claude/projects, opened read-only.
  3. 03Costs are computed locally — against a dated price table shipped in the package.
  4. 04One HTML file is written — self-contained, no external references.

Nothing leaves the machine.

Which is why it installs without a security review.

No network
Ships importing fs, os, path, url. No HTTP client, no telemetry.
No dependencies
Node built-ins only. No transitive tree to audit.
Paths redacted
Folder names encode your username. Stripped by default; --show-paths opts in.
No conversation data
Token counts, model ids and timestamps. Never message content.
